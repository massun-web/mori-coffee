# MORI COFFEE & BAKERY

架空のカフェ＆ベーカリーを想定した、Web制作のポートフォリオサイトです。HTML・CSS・JavaScriptを使用して制作しました。

**公開サイト：** [MORI COFFEE & BAKERY](https://mssunn.github.io/mori-coffee/)

## 目的・コンセプト

「パンが焼ける朝、珈琲の香る場所。」をコンセプトに、お店の雰囲気やコーヒー・パンへのこだわりを伝えるサイトを目指しました。メニューや価格、季節のおすすめ、店舗情報を1ページにまとめています。

アイボリーと深いグリーンを基調に、写真と余白を使って、落ち着いて過ごせるカフェの雰囲気を表現しました。

## 使用技術

- HTML：ページ構成、メニュー・店舗情報の掲載
- CSS：レイアウト、装飾、レスポンシブ対応
- JavaScript：メニューの開閉、スクロール時の表示、案内ダイアログ

## 主な機能・工夫

- **スマートフォン・PCに対応**：画面幅に応じて写真と文章の配置を変更し、スマートフォンでは縦1列に表示します。
- **スマートフォン用メニュー**：ボタンで開閉でき、リンク選択時やEscキーでも閉じられます。
- **ページ内ナビゲーション**：各セクションへ移動でき、ページ上部へ戻るリンクも設置しています。
- **読みやすさへの配慮**：スマートフォンの補助文字のサイズを調整し、コーヒーメニューの価格の書き始めを揃えています。
- **操作への配慮**：画像の代替テキスト、本文へスキップするリンク、キーボード操作時のフォーカス表示を用意しています。
- **スクロール時のアニメーション**：内容が順に表示されます。動きを減らす設定にも対応しています。
- **Instagramの案内**：実在の店舗アカウントへ誘導せず、架空ブランドであることをダイアログで案内します。

## 表示・動作確認

Microsoft Edgeで、画面幅320〜1440pxの8種類の表示を確認しました。横方向のはみ出し、画像・ページ内リンク、メニューと案内ダイアログの操作、JavaScriptの実行エラーを確認しています。

スマートフォン表示はブラウザーで画面幅を変更して確認したもので、実機での検証は行っていません。

## ローカルでの閲覧

`index.html` をブラウザーで開くと閲覧できます。ビルドやパッケージのインストールは不要です。Google Fontsの読み込みにはインターネット接続が必要です。

## 掲載情報について

このサイトは架空の店舗を題材にしたポートフォリオ作品です。掲載されている店舗・所在地・営業時間などはすべて架空のものです。メニュー・価格・ニュースも作品用の設定であり、実店舗の案内ではありません。
