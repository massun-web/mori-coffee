# MORI COFFEE & BAKERY

架空のカフェ＆ベーカリーのブランドサイト。HTML・CSS・JavaScriptだけで作成した、ポートフォリオ用のオリジナル作品です。

## サイトの開き方

1. このフォルダーの `index.html` をダブルクリックします。
2. ChromeやEdgeなどのブラウザーでサイトが開きます。インストールやビルドは不要です。
3. 最新の変更が表示されない場合は `Ctrl + F5` で再読み込みしてください。

写真はすべて `assets` 内に保存しています。Google Fontsの読み込みにはインターネット接続が必要ですが、接続できない場合も標準フォントで表示されます。

## ファイルの役割

- `index.html`：文章、メニュー、価格、営業時間などの内容。
- `style.css`：色、文字、余白、写真の配置、スマートフォン対応。
- `script.js`：スマートフォンのメニュー、スクロールアニメーション、Instagram案内。
- `assets/`：写真5点とオリジナルのSVGファビコン。
- `preview/desktop.png`、`preview/mobile.png`：ブラウザーで撮影した完成ページ全体の画像。
- `tools/verify.mjs`：表示と操作を確認する開発用スクリプト。閲覧時には不要です。

## 確認するところ

- 上部のCONCEPT・COFFEE・BAKERY・SEASONAL・VISIT USから各セクションに移動できます。
- ブラウザーの幅を狭くすると、1列のレイアウトとMENUボタンに切り替わります。
- MENUは再度押すか、リンクを選ぶか、Escキーで閉じられます。
- Instagramボタンで架空ブランドであることの案内が開きます。閉じるボタン、枠外のクリック、Escキーで閉じられます。
- Tabキーでリンクやボタンへ移動できます。
- OSの「視差効果を減らす」などの設定に応じてアニメーションを停止します。
- JavaScriptが無効でもページ本文は表示されます。

## デザイン

アイボリー・深いグリーン・ダークブラウンを使用。明朝体の日本語とセリフ体の英語、大きな写真、余白でブランドの雰囲気を表現しました。汎用カードを並べず、左右交互の写真配置と誌面風のタイポグラフィで展開しています。

## 架空情報について

店舗、所在地、メニュー、価格、営業時間、ニュースは作品のための設定です。実在する所在地への地図や電話番号は掲載していません。Instagramの実在アカウントには紐付けていません。実店舗向けに転用する場合は店舗情報を差し替え、`data-instagram` のボタンを公式URLへのリンクに変更してください。

## 実施した動作確認

Microsoft Edgeのヘッドレスブラウザーで確認しました。

- 画面幅1440 / 1024 / 768 / 390 / 320pxで横方向のはみ出しなし。
- 写真5点の読み込み、画像の代替テキスト、ページ内リンクを確認。
- スクロールによる表示、スマートフォンメニューの開閉、Escキー、リンク選択後のフォーカス移動を確認。
- Instagram案内の表示とEscキーによる終了を確認。
- アニメーションを減らす設定への対応、JavaScript実行エラーがないことを確認。

Node.js 22以降と標準の場所にインストールされたWindows版Edgeがある場合、`node tools/verify.mjs` で再確認できます。実行すると `preview` の画像を更新し、OSの一時フォルダーに検証専用のブラウザープロファイルを作成します。普段使っているブラウザーのプロファイルは使用しません。
